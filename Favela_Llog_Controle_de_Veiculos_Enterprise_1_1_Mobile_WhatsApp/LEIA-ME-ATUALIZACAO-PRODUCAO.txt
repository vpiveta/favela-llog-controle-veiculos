FAVELA LLOG CONTROLE DE VEICULOS - PACOTE UNICO DE PRODUCAO

NOME DA PASTA (mantido para o Render):
Favela_Llog_Controle_de_Veiculos_Enterprise_1_1_Mobile_WhatsApp

COMO PUBLICAR:
1. Extraia todo o ZIP para uma pasta normal do Windows.
2. Nao execute o BAT de dentro da visualizacao do ZIP.
3. Abra PUBLICAR_GITHUB.bat dentro da pasta extraida.
4. Se o navegador abrir, entre na conta do GitHub que possui acesso ao repositorio.
5. Aguarde a mensagem PUBLICACAO CONCLUIDA COM SUCESSO.

O publicador nao depende mais da pasta oculta .git. Ele baixa uma copia limpa do
repositorio, envia somente os arquivos seguros do sistema e nao publica .env,
banco local, comprovantes, ambiente virtual ou arquivos ZIP.

VALIDACAO ANTES DE PUBLICAR:
1. Abra TESTAR_HOMOLOGACAO.bat.
2. Aguarde a mensagem HOMOLOGACAO APROVADA.
3. Abra PUBLICAR_GITHUB.bat.
4. Aguarde as quatro etapas; a mensagem da atualizacao e criada automaticamente.

SE APARECER ERRO:
- "Git nao esta instalado": instale https://git-scm.com/download/win e mantenha
  o Git Credential Manager selecionado durante a instalacao.
- "Nao foi possivel acessar o repositorio": confira internet e acesso a conta.
- "Envio ao GitHub nao foi autorizado": entre no GitHub pelo navegador, execute
  o BAT novamente e conclua a autorizacao. Nunca envie senha ou token por chat.
